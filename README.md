# 🛒 Ứng Dụng Quản Lý Thẻ Thành Viên Siêu Thị (XML & Java)

Dự án thuộc môn học **Các Hệ Thống Mã Nguồn Mở**.  
Ứng dụng minh họa việc kết hợp ngôn ngữ Java với định dạng lưu trữ cấu trúc **XML** (DOM Parser) để quản lý thẻ thành viên siêu thị.

## 📌 Tính năng chính
- 📄 **Xem danh sách**: Đọc toàn bộ dữ liệu từ file `thanhvien.xml`.
- ➕ **Thêm thành viên**: Ghi dữ liệu thành viên mới trực tiếp vào file XML.
- 🎯 **Tích điểm**: Cập nhật giá trị thẻ trong cấu trúc cây XML.
- 🔍 **Tìm kiếm**: Tìm thông tin thẻ theo mã.

## 🛠️ Công nghệ sử dụng
- **Ngôn ngữ**: Java (JDK 8 trở lên)
- **Định dạng dữ liệu**: XML (`thanhvien.xml`), Schema XML (`thanhvien.xsd`)
- **XML Parser**: W3C DOM Parser (`javax.xml.parsers`)
- **IDE**: Visual Studio Code
