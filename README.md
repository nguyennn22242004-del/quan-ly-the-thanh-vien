# Dự Án Quản Lý Thẻ Thành Viên Siêu Thị (Supermarket Membership Management)

Ứng dụng quản lý thẻ thành viên siêu thị viết bằng ngôn ngữ Java (Console Application).

## 🚀 Chức năng chính
- Quản lý thông tin thành viên (Mã thẻ, Tên, Số điện thoại, Điểm tích lũy).
- Tự động phân hạng thẻ dựa trên điểm tích lũy (Bạc, Vàng, Kim Cương).
- Thêm mới thành viên, tìm kiếm thành viên theo mã.
- Tích điểm khi khách hàng mua sắm.

## 🛠 Lập trình
- Ngôn ngữ: Java
- Công cụ: Visual Studio Code
